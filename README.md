# LAST THREE — 残るのは新しい 3 つだけ

○と×を交互に置いて、縦・横・斜めに 3 つ並べたら勝ち。ただし盤に残るのは自分の新しい 3 つだけで、4 つ目を置くと一番古い印が消える。CPU 対戦・ふたり対戦。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/last-three/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

1. ○と×が交互に、空いているマスへ印を 1 つ置く。○ が先手。
2. 盤に残せる印は **ひとり 3 つまで**。4 つ目を置くと、**自分の一番古い印が消える**。次に消える印は薄く、点線で囲んで見せる。
3. 縦・横・斜めのどれかに **自分の印が 3 つ並んだら勝ち**（古い印を消したあとで調べる）。
4. 同じ局面（印の場所・古さの順・手番）が 3 回出たら引き分け。

- CPU と対戦（先手・後手を選べる）か、ふたりで 1 台を回して対戦。
- マスをタップして置く。PC では 1〜9 のキー（テンキーの並び。7 が左上）でも置ける。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
node test.mjs                 # 遊びの中身のテスト
```

- `game.js`: 遊びの中身（置く・消える・勝ち・引き分け・CPU）。DOM に触らない
- `main.js`: 画面・音・保存
- 保存: `last-three.settings`（モード・手番・音・遊び方を見たか）、`last-three.stats`（CPU 戦の勝ち・負け・引き分け）

## 設計メモ

- CPU「ふつう」は 4 手先まで読む minimax（αβ 枝刈り）。読みの終わりは「自分の印 2 つ＋空き 1 つの列」の数の差（次に消える印は数えない）。同じ点の手はランダム。
- 全部読み（後退解析）の結果: たどり着く局面は 116,074。はじめの局面は **先手必勝**（○ が辺のマス 1・3・5・7 に置くと 13 手で勝ち切れる。角・中央から始めると、どちらも勝ち切れない）。
